# 知乎阅读优化

一个 Stylus 样式，**三个 Code 分区**：全站界面、专栏阅读、列表页布局。前两个分区保留已验收效果；第三个分区基于用户提供的推荐页结构新增，不修改问答页正文。

当前列表页版本待真实页面验收。推荐页的左右栏结构已确认；关注、热榜、圈子和专栏广场只有路径已确认，若 DOM 不同，规则会暂时不生效，不能据此声称五页均已适配完成。

2. 在 Stylus 管理页**禁用**原来的「知乎 article」和「知乎全站优化」，先不要删除。
3. 在管理页的「备份 / Backup」区域使用「导入 / Import」，选择：

   ```text

   ```

4. 启用新增的 **「知乎阅读优化 · 整理版」**，确认编辑器里有三个 Code 分区。
5. 刷新页面，按下面的清单验收。

这是 **Stylus 管理页导入的 JSON 文件**，不是要粘贴进 CSS 编辑框的代码。文件不包含扩展设置、原样式 ID 或其他站点样式，不要求修改 Firefox 配置。

现有 Tampermonkey「知乎专栏：文首作者补充信息」脚本应当继续启用。Stylus 导出不包含这个脚本，本仓库没有假装备份它，也没有重新安装或改动它。

### 另一种导入方式 / 后续更新

`dist/zhihu-reading.css` 是相同内容的 **Mozilla-format CSS**：

1. 新建样式，或打开已有的「知乎阅读优化 · 整理版」。
2. 使用编辑器的「导入 / Import」按钮，粘贴这个文件的全部内容。
3. 选择 **Overwrite style**，保存。

这样会生成/替换三个分区（两个域名条件、一个 URL 正则条件）。后续更新推荐用这种方式明确替换现有样式，**不要继续 Append 补丁**。如果重复从管理页导入 JSON，请查看导入结果，确保没有留下多个同时启用的整理版。

### 回退

禁用整理版，重新启用两个旧样式即可。原始 Downloads 文件未被改动。

若只想撤销新增的列表页布局，在 Stylus 编辑器移除 Code 3 即可，前两个分区不受影响。Git 提交 `21b7cb1` 保存了新增列表页之前的两分区版本。

## Code 分区如何工作

| 分区 | Stylus 作用范围 | 内容 |
| --- | --- | --- |
| Code 1 | 域名 `zhihu.com` | 全站导航、搜索栏、直答、看山、解释入口 |
| Code 2 | 域名 `zhuanlan.zhihu.com` | 专栏正文宽度、留白、侧栏、目录、阴影 |
| Code 3 | `www.zhihu.com` 的五条入口路径，使用 URL 正则匹配 | 列表页右栏隐藏、信息流加宽居中、留白与阴影 |

域名匹配包含子域名。首页等五个入口应用 Code 1 + Code 3，问答页只应用 Code 1，专栏文章应用 Code 1 + Code 2。作用范围属于每个 Code 分区，不要求拆成独立样式。

Code 3 只匹配 HTTPS 下的 `/`、`/follow`、`/hot`、`/ring-feeds`、`/column-square`，允许可选末尾斜杠、查询参数和 hash；不匹配下级详情页、问答、搜索、个人主页或其他域名。不能用覆盖整个 `www.zhihu.com` 的域名条件替代它。

源码分别是 `src/global.css`、`src/article.css` 和 `src/home.css`。它们**不含** `@-moz-document` 外壳；构建时生成 JSON 的 `domains` / `regexps` 或 Mozilla-format CSS 的对应条件。

## 保留的最终效果

### 全站

- 隐藏顶部 AI Works、故事、直答。
- 隐藏看山入口和操作栏的「解释这篇内容」。
- 保留关注、推荐、热榜、专栏、圈子、`+`、返回顶部及常规互动按钮。
- 搜索框解除 365px 最大宽度，填满可用区域。
- 搜索区域内部按钮间距、与左侧导航间距均为 16 CSS px。

### 专栏

- 单栏居中；最大阅读区域宽度 **1200 CSS px**。
- 正文卡片左右留白 `clamp(24px, 5vw, 64px)`。
- 阴影 `0 1px 6px rgba(18, 18, 18, 0.10)`。
- 隐藏侧栏整列，但保留 DOM，兼容现有作者补充信息脚本。
- 目录入口宽 76px，外层左偏移 -92px，保持与正文 16px 的间隔。
- 保留目录内部 sticky 定位，不新增 `overflow: hidden`。

以上全站和专栏规则均来自原备份的最终有效值。浏览器缩放会放大 CSS 像素对应的视觉尺寸。

### 新增：列表页（待验收）

- 根据已提供的推荐页 `.Topstory-container` / `.Topstory-mainColumn` / `.css-bkewaf` 结构处理布局。
- 隐藏右侧整列，包含创作中心、大家都在搜、作者平台等。
- 信息流单栏居中，最大总宽 1100 CSS px，窗口两侧合计至少 32px。
- 主栏左右内边距 `clamp(20px, 3vw, 40px)`，白色背景和轻阴影；卡片自身的内边距保留，可能与主栏留白叠加。
- 保留左栏顶部发布入口、摘要折叠、正常互动与加载行为，不猜测卡片内部 DOM。

## 修改与构建

**只编辑 `src/`，不要手动修改生成文件。**

```bash
cd /home/Catwine/Workspace/zhihu-reading
python3 scripts/build.py
python3 scripts/build.py --check
```

构建只用 Python 标准库，输出可重复，不携带构建时间戳。`dist/` 随 Git 提交，便于直接导入及查看版本差异。

测试使用 `uv` 管理开发依赖：

```bash
uv sync --locked
uv run python -m unittest discover -s tests -v
```

测试需要 Playwright Firefox。优先使用所需版本，若未安装则尝试本机已有的 Playwright Firefox 缓存；也可以通过 `PLAYWRIGHT_FIREFOX_EXECUTABLE` 指定。若没有浏览器或缓存版本不兼容，再执行：

```bash
uv run playwright install firefox
```

测试运行在全新的临时浏览器上下文内，拦截全部网络请求，不读取日常 Firefox 的个人配置、Cookie 或真实知乎页面。

- CSS 语法及同一选择器内的重复属性检查。
- JSON、Mozilla-format CSS 和源码内容一致。
- 离线 Firefox 中比较整理前后的计算样式和元素矩形。
- 1339 / 1000 / 720 CSS px 三种宽度、三个域名条件；原两个样式的两种加载顺序。
- 入口隐藏、正常按钮保留、最终正文宽度/留白/阴影、目录定位、搜索框间距。
- 列表页 URL 正则的 Python / JavaScript 匹配，包括 query、hash、末尾斜杠和排除路径。
- 推荐页结构夹具在五条路径、1339 / 1000 / 720 / 390px 宽度下的右栏隐藏和主栏居中；**不代表已获得其他四页的真实 DOM**。
- 列表页规则不泄漏到问答、个人主页、搜索或专栏文章，未知布局保持不变。

**离线回归不等于真实页面验收。** 夹具依据已提供的 DOM 结构构造，不包含完整知乎页面、脚本动态行为或 Stylus 扩展自身的导入流程；窄窗口回归仅证明整理前后一致，并不保证原布局没有窄屏问题。
